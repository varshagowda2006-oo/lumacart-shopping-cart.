# LumaCart 🛍️

A modern and responsive e-commerce shopping cart web application built with React and Vite.

## 🌐 Live Demo

[View LumaCart](https://lumacart-e-commerce-gg1q.bolt.host)

## ✨ Features

- Product browsing and search
- Category filtering and sorting
- Product details
- Shopping cart
- Wishlist
- Quantity management
- Checkout
- Order confirmation
- Order cancellation
- Order history
- Responsive design
- LocalStorage for cart, wishlist and order data

## 🛠️ Technologies Used

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Lucide React
- LocalStorage
